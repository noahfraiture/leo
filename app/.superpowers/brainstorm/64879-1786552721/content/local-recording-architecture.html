Recording and analysis without Synology

The app records each camera directly into the session folder, then analysis reads those same files.

1. During the software session
Camera RTSPlive H.264/H.265 stream
→
Recorder supervisorruns FFmpeg and reconnects
→
Local MKV segmentstream copied, no re-encoding
2. A temporary camera disconnection creates a gap, not a failed session
camera-2 / segment A10:00:00–10:04:12
→
GAP18 sec
→
camera-2 / segment B10:04:30–10:10:00

The supervisor retries until Stop. Other cameras keep recording. Both recovered segments remain usable.

3. The complete portable session on the host or SSD
data/sessions/1786552800000/
├── events.jsonl        session clock and operator actions
├── recordings/
│   ├── camera-1/*.mkv
│   └── camera-2/*.mkv
└── analysis.json      progress and results
4. After Stop, analysis reads the local files directly
events.jsonlwhich timestamps to sample
MKV segmentswhere recorded frames live
→
FFmpegextract selected JPEG frames
→
AI analysischeckpoint after each batch
→
analysis.jsonwarnings, progress, results
What disappears: Synology server, HTTP catalogue, authentication, downloads, simulator, and temporary video copies. A missing sample inside a red gap is skipped; analysis resumes from segment B.
